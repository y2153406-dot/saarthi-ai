# Saarthi AI 🤖

An AI-powered web application built with Django that provides users with an intelligent and interactive platform powered by modern AI technology.

Saarthi AI focuses on integrating Artificial Intelligence into a Django web application while implementing secure authentication, API integration, database management, and production deployment.
